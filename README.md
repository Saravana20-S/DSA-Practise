# DSA-Practise

A Java-based collection of Data Structure implementations developed from scratch for learning and practicing core Data Structures and Algorithms. Each module focuses on implementing the data structure and its operations without relying on Java's built-in implementations.

## Project Structure

```
DSA-Practise
│
├── binarysearchtree/
├── hashtable/
├── linkedlist/
├── queue/
├── sortedlinkedlist/
├── stack/
└── README.md
```

## Implementations

### Linked List
- Singly Linked List
- Insert Operations
- Delete Operations
- Search
- Traversal

### Sorted Linked List
- Sorted Insertion
- Ordered Traversal

### Stack
- Stack Implementation using Linked List
- Push
- Pop
- Peek
- IsEmpty

### Queue
- Queue Implementation using Linked List
- Enqueue
- Dequeue
- Front
- IsEmpty

### Hash Table
- Custom Hash Table Implementation
- Hash Function
- Separate Chaining using Linked List
- Word Frequency Counter
- Search
- Remove

### Binary Search Tree
- Binary Search Tree Implementation
- Node Insertion
- Inorder Traversal
- Tree Size
- Recursive Search

## Technologies Used

- Java
- Object-Oriented Programming
- Generics
- Recursion

## Repository Structure

Each directory contains an independent implementation of a data structure along with its related operations and examples.
